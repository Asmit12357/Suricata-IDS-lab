# Suricata IDS Lab - Custom Rule Detection

## Overview
This project demonstrates the implementation of a network-based Intrusion Detection System using Suricata, focusing on detecting ICMP-based reconnaissance attacks.

## Features
- Custom IDS rule creation
- Detection of ICMP ping scans
- Log analysis using eve.json and fast.log
- Evidence-based validation with screenshots

## Tech Stack
- Suricata
- Kali Linux
- JSON Log Analysis

## Detection Workflow
1. Create custom rule
2. Generate attack traffic
3. Capture using Suricata
4. Analyze logs

## Evidence
See `/evidence` folder for detection proof.

## Key Learning
- Rule writing in Suricata
- Network traffic analysis
- IDS alert validation
